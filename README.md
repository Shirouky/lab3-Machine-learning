# Лабораторная работа №3: Кросс-валидация, подбор гиперпараметров, отбор признаков и ансамблирование

## Описание
Работа является продолжением предыдущих лабораторных. На основе трёх лучших моделей (логистическая регрессия, дерево решений, случайный лес), выбранных по результатам второй лабораторной, выполнены:

1. **Кросс-валидация (5‑fold)** для оценки стабильности моделей.
2. **Подбор гиперпараметров** с помощью `GridSearchCV` по метрике `F1-macro`.
3. **Отбор наиболее значимых признаков** с использованием `RFECV`.
4. **Построение итогового ансамбля** (стэкинг) и сравнительный анализ.

Все эксперименты проведены с фиксированными параметрами: `cv=5`, `scoring='f1_macro'`, `random_state=100`.

## Технологии
- **Python 3.8+**
- **pandas, numpy** – работа с данными
- **scikit-learn** – модели, кросс-валидация, GridSearchCV, RFECV, стэкинг
- **xgboost** – градиентный бустинг
- **matplotlib, seaborn** – визуализация
- **joblib** – сохранение моделей

## Функциональность

### 1. Предобработка данных
Используется та же предобработка, что и в ЛР №2:
- Замена пропусков целевой переменной на `"Healthy"`.
- Разделение `Blood Pressure` на систолическое и диастолическое давление.
- Кодирование категориальных признаков (LabelEncoder, One-Hot, порядковое кодирование BMI).
- Масштабирование числовых признаков (`StandardScaler`).
- Разбиение на обучающую (70%) и тестовую (30%) выборки.

### 2. Выбор трёх лучших моделей
На основе результатов предыдущей работы отобраны:
- Логистическая регрессия (базовая)
- Дерево решений (после тюнинга)
- Случайный лес (после тюнинга)

Для каждой модели проведена 5-кратная кросс-валидация с расчётом среднего `F1-macro` и его разброса. Построены ящичковые диаграммы для визуального сравнения стабильности.

### 3. GridSearchCV
Для каждой из трёх моделей выполнена настройка гиперпараметров с помощью `GridSearchCV`. Для логистической регрессии перебирались `C`, `solver`, `class_weight`, `max_iter`; для дерева решений – `max_depth`, `min_samples_split`, `min_samples_leaf`, `criterion`; для случайного леса – `n_estimators`, `max_depth`, `min_samples_split`, `min_samples_leaf`, `max_features`.

Поиск проводился по 5‑кратной кросс-валидации с оптимизацией `f1_macro`.

### 4. Отбор признаков (RFECV)
С помощью рекурсивного исключения признаков (`RFECV`) на основе случайного леса и логистической регрессии отобраны наиболее значимые признаки. Для случайного леса оптимальным оказалось 7 признаков, для логистической регрессии – 13. После отбора модели переобучены и оценены на тестовой выборке.

### 5. Ансамбль (стэкинг)
Построен стэкинг-ансамбль из трёх базовых моделей (логистическая регрессия, дерево решений, случайный лес) с мета-классификатором – логистической регрессией. Выполнено сравнение с индивидуальными моделями по метрикам `Accuracy`, `F1-macro`, `F1-weighted`.

### 6. Визуализация и сравнение
Для каждой модели построены:
- Матрицы ошибок (confusion matrix) на тестовой выборке.
- Ящичковые диаграммы (boxplot) результатов кросс-валидации.

## Результаты

### Кросс-валидация (без тюнинга)
| Модель              | Средний F1-macro | Разброс (min–max) |
|---------------------|------------------|-------------------|
| LogReg              | 0.872            | 0.818–0.909       |
| DecisionTree        | 0.849            | 0.815–0.901       |
| RandomForest        | 0.853            | 0.806–0.882       |
| Stacking            | 0.863            | 0.823–0.901       |
| XGBoost             | 0.856            | 0.817–0.901       |

Наиболее стабильной оказалась модель случайного леса (стандартное отклонение 0.028), а наивысшее среднее значение показала логистическая регрессия (0.872).

### GridSearchCV
- **Логистическая регрессия:** лучшие параметры `{'C': 5, 'class_weight': None, 'max_iter': 1000, 'solver': 'lbfgs'}`, CV F1-macro = 0.884, тестовый F1-macro = 0.881.
- **Дерево решений:** `{'criterion': 'gini', 'max_depth': 4, 'min_samples_leaf': 1, 'min_samples_split': 2}`, CV F1-macro = 0.875, тестовый F1-macro = 0.897.
- **Случайный лес:** `{'max_depth': None, 'max_features': 'sqrt', 'min_samples_leaf': 1, 'min_samples_split': 2, 'n_estimators': 100}`, CV F1-macro = 0.881, тестовый F1-macro = 0.867.

*Примечание:* для случайного леса тестовый результат оказался ниже, чем у базовой версии, что может указывать на переобучение при тюнинге.

### Отбор признаков (RFECV)
- **Случайный лес** – отобрано 7 признаков: `Age`, `Sleep Duration`, `Physical Activity Level`, `Systolic_BP`, `Diastolic_BP`, `Occ_Nurse`, `BMI_Category`. После отбора качество на тесте практически не изменилось, но стабильность кросс-валидации возросла.
- **Логистическая регрессия** – отобрано 13 признаков, включая пол, показатели сна, давления, а также большинство one-hot признаков профессий. После отбора тестовый F1-macro сохранился на уровне ~0.87.

### Итоговый ансамбль (стэкинг)
Стэкинг из трёх базовых моделей показал:
- Accuracy: 0.876
- F1-macro: 0.849
- F1-weighted: 0.879

Хотя стэкинг уступил лучшей индивидуальной модели (логистической регрессии с F1-macro ≈ 0.91), он превзошёл дерево решений и случайный лес, продемонстрировав хорошую обобщающую способность.

## Выводы
1. **Лучшей моделью** по тестовому F1-macro остаётся логистическая регрессия (≈0.91), что подтверждает её эффективность при хорошо разделимых данных.
2. **GridSearchCV** позволил улучшить качество дерева решений и логистической регрессии, но для случайного леса привёл к небольшому падению на тесте.
3. **Отбор признаков** (RFECV) упростил модели, сохранив при этом качество, что особенно важно для интерпретируемости.
4. **Стэкинг** дал результат, сравнимый с лучшими индивидуальными моделями, и оказался более стабильным на кросс-валидации, чем, например, XGBoost.
5. Рекомендованной моделью для практического использования является логистическая регрессия (простота, интерпретируемость, высокое качество). В случаях, когда требуется более высокая стабильность, предпочтителен случайный лес или стэкинг.
